# ClinicERP

Sistema ERP para gestão de consultórios médicos, desenvolvido com **Laravel + MySQL** (e evolução futura para React), com foco em aprender construindo um produto real.

## 🚀 Objetivo do projeto
Em **30 dias**, evoluir habilidades em:
- PHP
- Laravel
- MySQL
- APIs REST
- React (fase posterior)

Regra principal do projeto:

> Todo estudo precisa virar uma tela ou função do sistema.

Ou seja: estudar aplicando diretamente no ClinicERP.

---

## 🩺 Projeto final (visão geral)
O objetivo é chegar a um sistema com:
- Login e permissões
- Cadastro de pacientes
- Cadastro de médicos
- Agenda de consultas
- Prontuário básico
- Anamnese
- Prescrições
- Financeiro simples
- Relatórios
- Dashboard
- Envio de lembretes por WhatsApp
- API para integrações futuras

## 📅 Roadmap de 30 dias

### Semana 1 — Base do sistema

#### Dias 1 a 3 (fase atual)
**Criar projeto Laravel + banco MySQL**

Estudos:
- PHP básico
- Laravel: routes, controllers, views, migrations e models

Entregas:
- Tela de login
- Dashboard inicial
- Cadastro de usuários

> **Status atual:** ✅ etapa concluída em 29/04/2026.

#### Dias 4 a 7

- Pacientes
